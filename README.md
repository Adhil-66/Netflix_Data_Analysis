# Netflix Data Analysis Dashboard

## Project Overview
This project focuses on analyzing Netflix content using Power BI. The dashboard helps explore Netflix movies and TV shows through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

## Dashboard
The Power BI dashboard is available in this repository.

**Project File:** `netflix.pbix`

## Key Objectives
- Explore Netflix content distribution.
- Analyze Movies vs TV Shows.
- Understand content trends.
- Explore genres and country-wise distribution.

## How to View
1. Download the `netflix.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive dashboard.
